# BunBun Translations — pliki strony

Ten pakiet zawiera frontend strony, dane, assety oraz backend HTTP wymagany przez obecną wersję strony.

Uwaga: obecna wersja projektu ma backend `server.js`, który jest zintegrowany z Discordem (OAuth, sesje, API i klient discord.js). Dlatego nie można bezpiecznie uruchomić samego frontendu bez `server.js` i zależności z `package.json`.

Uruchomienie:
1. `npm install`
2. uzupełnij `.env` na podstawie `.env.example`
3. `npm start`
